## Описание проекта
Программный продукт представляет собой настольное приложение (Windows Forms, .NET 8.0) для автоматизации работы торговой компании «Чудо Обувь». 
Система позволяет вести учет товаров, просматривать каталог с фильтрацией и сортировкой, оформлять заказы и управлять ими. Реализована ролевая модель доступа: Гость, Авторизованный пользователь, Менеджер и Администратор.

## Структура репозитория
*   **`/SourceCode`** — исходный код приложения на C# (Visual Studio Solution).
*   **`/Database`** — SQL-скрипт структуры БД (`ChudoObuv_Schema.sql`), резервная копия базы данных (`ChudoObuv.bak`) и ER-диаграмма в формате PDF.
*   **`/CompiledApp`** — готовое к запуску скомпилированное приложение (Release версия).

## Инструкция по развертыванию и запуску
1.  Разверните базу данных на локальном сервере SQL Server. 
    *   Вы можете восстановить базу из файла `/Database/ChudoObuv.bak`.
    *   Или выполнить скрипт `/Database/ChudoObuv_Schema.sql` для создания структуры.
2.  При необходимости измените строку подключения в файле `/CompiledApp/ChudoObuv.dll.config` (или `App.config` в исходниках), указав ваш экземпляр SQL Server.
3.  Запустите приложение `/CompiledApp/ChudoObuv.exe`.
